# Data folder — SYNTHETIC supplier invoices

**All 240 invoices are SYNTHETIC.** Supplier and customer names are
built from Irish place names plus a business type (for example "Corrib
IT Services Ltd"); VAT numbers are random strings in the Irish format
(`IE` + 7 digits + 1–2 letters) and are not checked against Revenue;
amounts, dates and line items are random. Each PDF has a visible
"SYNTHETIC EXAMPLE INVOICE" footer, and every ground-truth row has
`source_flag = SYNTHETIC_EXAMPLE_DATA` (the evaluation script refuses
to run otherwise).

| Path | Content |
| --- | --- |
| `invoices_pdf/` | 240 one-page PDFs: 60 each in layouts A, B, C (development) and D (held out) |
| `SYNTHETIC_invoice_ground_truth.csv` | The true value of the 8 target fields for every PDF |
| `ocr_text/` | Cached OCR output for the 114 test invoices (simulated scans), so results can be reproduced without re-running OCR |

Layouts differ in where fields sit and what they are called:

| Field | A | B | C | D (held out) |
| --- | --- | --- | --- | --- |
| Invoice number | `Invoice No:` INV-2026-0042 | `Invoice #:` 004213 | `Ref:` AB-12345 | `Document number:` 2026/00042 |
| Issue date | `Invoice Date:` 15/11/2026 | `Date:` 15 Nov 2026 | `Issued:` 2026-11-15 | `Dated:` November 15, 2026 |
| Due date | `Due Date:` | `Payment due:` | `Due:` | `Pay by:` |
| Net / VAT / total | Subtotal / VAT @ 23% / Total Due | Net amount / VAT (23%) / Amount payable (one line) | Goods total / Tax 23% / Grand Total | Total excl. VAT / VAT amount / Balance to pay |
| Distractor IDs | Customer Ref, phone | PO number, phone | Account, phone | Order ref, phone |

Generated by `src/generate_invoices.py` (seed 7). VAT rates are 23% or
13.5%.
